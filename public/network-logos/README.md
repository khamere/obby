# Network wordmarks

These 31 SVG wordmarks were extracted from the network logo section of
**The Lounge – User Display**, version 1.0.20, by **ThatNeoByte**, supplied by
the user. The userscript declares the MIT license.

Source: https://git.tnb.moe/NeoByte/UserScripts/src/branch/main/TheLounge/TheLounge-UserDisplay.user.js

Artwork is bundled locally and rendered as images. References inside the SVGs
are limited to internal fragments and embedded PNGs. No tracker requests,
userscript execution, avatars, profile scraping, or tracker credentials are used.
Brand names and logos remain the property of their respective owners.

Matching is defined in `src/lib/networkLogos.json`. Match upstream hostnames
exactly; never assign one tracker's logo to an entire shared IRC network.
Blutopia's placeholder `irc.` host from the userscript is deliberately omitted;
its named connection can still use the wordmark.
