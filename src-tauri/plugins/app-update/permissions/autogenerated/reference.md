## Default Permission

Lets the app download a release APK, follow its progress, cancel it and hand it to Android's installer.

#### This default permission set includes the following:

- `allow-start-download`
- `allow-cancel-download`
- `allow-download-status`
- `allow-open-install-settings`
- `allow-retry-install`
- `allow-register-listener`
